# Tasks

Forty-four tasks across four one-week sprints, each with the person who owns it; tick them off as they land. Each task matches a work item in the Perception LMS (KAN) Jira project.

Our lecturer sets a deliverable each week. Each one gets its own epic in Jira and its own list at the top of that week's sprint.
