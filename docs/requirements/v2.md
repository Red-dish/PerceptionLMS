Tracked as GitHub Epic 6 #118 (Jira KAN-81).
- **Client scenario:** make the LMS smarter than Canvas with AI. It asks whether AI could predict which students need support, whether students could ask a chatbot about their courses, and whether the system could recommend what to study next. The team is invited to investigate and suggest its own ideas. Only the at-risk prediction has set tasks.
- **Task 1:** explore `students_demo.csv` (400 fictional students: attendance, quiz average, missed assignments, weekly logins, days since login, at_risk) and answer 4 questions. GitHub #119.
- **Task 2:** train a **Decision Tree** classifier on the five activity columns, with `at_risk` as the target and an 80/20 train/test split. Show the accuracy, save the model, and test it on one new fictional student. Answer: the algorithm's name, what training means, training vs testing data, and the accuracy achieved. GitHub #120. (The team's first model was logistic regression instead; see v2.1.)
- **From the scenario, not set tasks:** a course chatbot (#123) and study recommendations (#124), planned for 25 Nov.
