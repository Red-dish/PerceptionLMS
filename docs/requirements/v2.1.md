# v2.1: team decisions

**Status:** partly kept. Logistic regression carries on as the v2 model; the rest was superseded by v3 on 18 Nov 2026. **Date:** 17–18 Nov 2026. **Source:** the team (not the lecturer).
**Code:** archived in [ml/archive/v2.1-student-risk-qwen/](../../ml/archive/v2.1-student-risk-qwen/ARCHIVE.md), Git tag `requirements-v2.1`.

Decided by the team while working on v2; never requested by the lecturer.
- **Kept:** logistic regression as the main model (first run: 77.5% accuracy, 39.1% at-risk recall, untuned).
- **Superseded:**
  - A `test-student` role for the 400 fictional students, unable to sign in; an admin CSV import; search and a role filter on the Users page. v3 scores five demo students who can sign in instead.
  - Qwen3.5-0.8B (fine-tuned outside the team, on synthetic data) as a second opinion, in its own 8 GB Lambda.
  - A lecturer chatbot to ask questions about the imported CSV through Qwen, with the ML model predicting behind the scenes.
- **Why Qwen isn't needed:** the at-risk prediction is ML, not a language model, and the lecturer allows a third-party chatbot. Whether the site chatbot uses our own local model is still to be decided.
- **Details:** the plan and handover are in `ml/archive/v2.1-student-risk-qwen/plan.md` (never carried out).
