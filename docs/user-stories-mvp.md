# Task 3: User Stories & MVP Scope

## User Stories

1. **Student Dashboard:** As a student, I want to view my enrolled courses and upcoming deadlines so that I can organise my studies.

2. **Course Materials:** As a student, I want to access course modules and learning resources so that I can study online.

3. **Assignment Submission:** As a student, I want to submit assignments online so that I can complete assessments through the LMS.

4. **Grades and Feedback:** As a student, I want to view my grades and lecturer feedback so that I can track my academic progress.

5. **Course Management:** As a lecturer, I want to upload learning materials and manage course content so that students can access relevant resources.

6. **Assignment Management:** As a lecturer, I want to create assignments, set deadlines, and grade submissions so that I can manage assessments efficiently.

7. **Announcements:** As a lecturer, I want to publish course announcements so that students receive important updates.

8. **User Management:** As an administrator, I want to manage users and course enrollments so that the correct people have access to the platform.

## MVP Scope

The first version of ASA LMS will prioritise login, dashboards, courses, learning materials, assignment submissions, grades, and announcements. Features such as discussion forums, advanced notifications, and analytics can be considered for future releases.

## Acceptance Criteria

- Students can access only their authorised courses and personal grades.
- Students can view assignments and submit supported files or text.
- Lecturers can manage course materials, assignments, and feedback for their courses.
- Administrators can manage users and enrollments.
- The system validates inputs and confirms successful actions.
