Perception LMS – UI/UX Design

1. Introduction

This paper describes UI/UX design factors of the proposed Learning Management System (LMS), known as the Perception LMS, for ASA College. Being a Lead UI/UX Designer, the author needs to develop an interactive, user-friendly, and accessible interface, which will serve as a convenient way to interact between students, teachers, administrators, and super administrators. The interactive prototype of the system was created using Canva AI. It includes the features such as simple navigation, clear layout, and role-based dashboards. This prototype demonstrates interaction with the proposed system before its development by the development team.

2. Design Objectives

The major design goals are as follows:
• Create a modern and professional learning environment;
• Ensure simple and consistent navigation;
• Make the interface accessible and usable;
• Design responsive layouts for various screen sizes;
• Accommodate diverse user roles and responsibilities;
• Make access to academic information easy;
• Increase student engagement via progress monitoring and clear dashboard information.

4. User Roles and Dashboards

Student Dashboard

The student interface focuses on academic activities and learning progress. Major design features are as follows:
- Courses overview;
- Upcoming assignments;
- Academic performance metrics;
- Information about attendance;
- Visual representation of learning progress;
- Navigation to grades, calendar, and profile;

Teacher Dashboard

The teacher interface is supposed to support instructional activities and academic management. Major design features are as follows:
- Courses management;
- Assignments management;
- Information about student learning;
- Navigation to grades and assessment;
- Teaching activities.

Administrator Dashboard

The administrator interface highlights academic operations. Major design features are as follows:
- Course catalog;
- Course management;
- Administration of students and teachers;
- Enrolment management;
- Overview of academic information.

Super Administrator Dashboard

The super administrator interface is focused on platform management. Major design features are as follows:
- Platform overview;
- User management;
- Roles and permissions;
- System settings;
- Interface for auditing and reporting.

5. UI Design System

The interface follows a consistent visual design system.

Color Scheme

The main color scheme of the design is the academic green one with neutral backgrounds and readable text colors.

Typography

Sans-serif typography is used to ensure readability on all dashboards, navigation menus, and content blocks.

Layout

The interface consists of the following components:
- Sidebar navigation;
- Dashboard cards;
- Consistent spacing;
- Clear page headings;
- Organized information sections;
- Academic progress visual indicators.

Consistency

Similar components are designed according to the same design patterns on different user workspaces.

6. UX Considerations

The prototype is designed according to the following principles:
- Simplicity: essential academic information should be easily located;
- Consistency: similar navigation and interface elements should have predictable behavior;
- Accessibility: the design tries to ensure legible text, transparent navigation, and accessible interactions;
- Efficiency: users should have easy access to commonly used functions;
- Engagement: progress indicators and academic summaries will help students understand their learning activities.

Some additional accessibility and usability testing will be required during the development.

7. Authentication and Role-Based Access

The proposed LMS will require distinct authenticated access for the following user roles:
- Students;
- Teachers;
- Administrators;
- Super Administrators.

At the moment, the Canva AI prototype implements only the demonstration-based role navigation. Password-based authentication has not been implemented because of the limitations of the Canva Code environment. It will be the responsibility of the development team to implement secure authentication, session management, and backend enforced role-based access.

8. Prototype Limitations

The current prototype mainly demonstrates the proposed user interface and user experience. Some features might use demonstration data and interactions. The following issues need to be implemented or verified in the future:
- Secure user authentication;
- Backend integration;
- Database connection;
- Persistent academic records;
- Production-level role permissions;
- Assignment submission flow implementation;
- Responsive behavior across devices;
- Accessibility compliance testing.

9. Future Improvements
